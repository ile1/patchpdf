What should change

AI never redraws the document. It returns a short list of ops (which line, what text). You apply them to the same PDF bytes.

Who plans it

Local patterns — no key, no network. Cloud models get a text snapshot only (not the PDF file). Keys ride your session; cloud calls go through an allowlisted proxy so the browser can talk to the provider.

Log
