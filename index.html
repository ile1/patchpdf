Instruction
Provider

Local patterns need no key. Cloud providers use a same-origin proxy so your key is not stored on our servers — only forwarded to the provider you pick. PDF bytes never leave your device for planning: only the text snapshot is sent to the model you choose.

Result

Privacy: extract / apply / DOCX run entirely in your browser (pdf.js + pdf-lib). There is no server character quota on the document — only a soft 400k-char prompt budget when you use AI, so provider APIs stay happy. Visual “cover” is not forensic redaction. Open-source-ready lib lives in this folder (engine.js).
